# Crypto Price Converter

A simple cryptocurrency price converter built with HTML, CSS and JavaScript.

## Features

- Bitcoin, Ethereum and Solana
- Custom coin amount
- Instant USD conversion
- Responsive interface
- No external dependencies
- No API keys required

## Technologies

- HTML
- CSS
- JavaScript

## Note

The displayed cryptocurrency prices are static demonstration values and are not live market prices.

## Purpose

This project was created as a small educational Web3 frontend project.
